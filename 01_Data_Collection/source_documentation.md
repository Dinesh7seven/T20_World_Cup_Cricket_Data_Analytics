# Data Collection

## Overview
This folder documents the data collection and preparation process for the T20 World Cup Cricket Analytics project.

## Dataset Files
The project uses the following cricket summary datasets:

- `batting_summary.csv` — contains batting statistics such as runs, strike rate, fours, and sixes.
- `bowling_summary.csv` — contains bowling statistics such as wickets, runs conceded, and bowling economy.

## Data Source
The original dataset was obtained from an external cricket data source and processed for analysis.

## Data Preparation
The data preparation process includes:

1. Identifying the relevant batting and bowling files.
2. Inspecting column names and data types.
3. Checking for missing values and duplicate records.
4. Verifying numerical statistics and calculated metrics.
5. Preparing the datasets for Python, SQL, and Power BI analysis.

## Data Scope
The dataset's match coverage must be verified before interpreting the results as statistics from the Men's T20 World Cup 2024 exclusively.
