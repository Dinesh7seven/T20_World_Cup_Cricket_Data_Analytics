POWER BI READY BUNDLE
=====================

This bundle contains the two CSVs, a Power BI theme JSON, and the exact DAX/report specification.

To create a genuine PBIX:
1. Open Power BI Desktop.
2. Home > Get data > Text/CSV. Import Data/batting_summary.csv and Data/bowling_summary.csv.
3. Select Transform Data only if you need to check data types, then Close & Apply.
4. Add the measures in DAX_and_Report_Specification.txt.
5. Build the three pages using the visual field assignments in that file.
6. Optional: View > Themes > Browse for themes, select T20_Cricket_Theme.json.
7. File > Save As > T20_World_Cup_Analytics.pbix.

I cannot author or save the actual .pbix container in this environment because Power BI Desktop's report-authoring engine is unavailable here. This bundle is Power BI-ready source material, not a PBIX file.
