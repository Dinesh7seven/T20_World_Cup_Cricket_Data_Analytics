# 🏏 T20 World Cup Cricket Analytics

An end-to-end cricket data analytics project using **Python, SQL, and Power BI** to explore batting performance, bowling performance, and player statistics.

## 📌 Project Overview

This project analyzes T20 cricket data to identify player performance patterns, compare batting and bowling contributions, and develop insights through data analysis and visualization.

The project demonstrates practical skills in data cleaning, exploratory data analysis, SQL querying, data modeling, and dashboard development.

## 🎯 Project Objectives

- Analyze batting performance using runs, strike rate, fours, and sixes.
- Evaluate bowling performance using wickets, runs conceded, and economy rate.
- Identify top-performing batters and bowlers.
- Compare player performance using statistical measures.
- Develop an interactive dashboard for exploring cricket statistics.
- Practice an end-to-end analytics workflow.

## 🔍 Analysis Workflow

1. **Data Collection:** Gather cricket data from available datasets.
2. **Data Preparation:** Inspect columns, handle missing values, and check data consistency.
3. **Python Analysis:** Use Pandas for data processing and exploratory analysis.
4. **SQL Analysis:** Query player statistics and calculate performance metrics.
5. **Power BI Dashboard:** Present batting and bowling KPIs through visualizations.
6. **Validation:** Verify calculations, data coverage, and consistency of reported statistics.
