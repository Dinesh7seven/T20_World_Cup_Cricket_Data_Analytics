# T20 World Cup Cricket Analytics

## Project Overview
This project analyzes cricket batting and bowling performance using Python, SQL, and Power BI.

## Objectives
- Analyze individual batting performance.
- Compare player runs, strike rates, fours, and sixes.
- Evaluate bowling wickets, economy rates, and runs conceded.
- Present player-performance insights through dashboard visualizations.

## Tools and Technologies
- **Python:** Data cleaning and analysis
- **SQL:** Aggregations, joins, CTEs, and window functions
- **Power BI:** Dashboard development
- **Pandas and Matplotlib:** Data analysis and visualization

## Project Structure
- `02_Data/` — datasets and processed summaries
- `03_Python_Analysis/` — Python analysis scripts and notebooks
- `04_SQL/` — SQL queries
- `05_Power_BI/` — Power BI report and related files

## Key Deliverables
- Batting summary dataset
- Bowling summary dataset
- SQL analysis queries
- Python analysis
- Power BI dashboard

## Data Quality Note
The scope of the supplied player summaries has not yet been independently verified as limited to the Men's T20 World Cup 2024. Tournament-specific conclusions should be confirmed against the original source data before publication.

## How to Use
1. Download or clone the repository.
2. Review the datasets and Python analysis.
3. Execute the SQL scripts in a compatible database.
4. Open the Power BI report in Power BI Desktop when the `.pbix` file is available.
